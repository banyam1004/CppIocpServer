## 프로젝트 소개
### C++ Winsock기반 멀티스레드 채팅 서버

## 개발 배경 및 목적
### Java서버에서 C++로 넘어오면서 1클라이언트 1스레드 방식의 한계를 체감하기 위해 구현

## 기술 스택
### C++ / Winsock2 / std::thread / std::mutex

## 주요 기능
- 다중 클라이언트 접속
- 브로드캐스트
- 수신/송신 스레드 분리
- 서버 구조

## 전체 흐름
1. 서버 시작 -> 소켓 생성 -> bind -> listen -> 클라이언트 대기
2. 클라이언트 접속 -> 전용 스레드 생성 -> clients 목록에 추가
3. 클라이언트 메시지 수신 -> 전체 브로드캐스트
4. 클라이언트 종료 -> clients 목록에서 제거 -> 소켓 닫기

## 스레드 구조
- 메인 스레드: accept() 로 클라이언트 접속 대기
- 클라이언트 스레드: 클라이언트마다 1개 생성, recv()로 메시지 수신

## 동시성 처리
- clients 목록: std::mutex + std::lock_guard로 동시 접근 제어
- 브로드캐스트: lock잡고 전체 클라이언트에 send()

## 한계점
- 클라이언트 수 = 스레드 수
- 동시 접속자 증가 시 메모리 사용량 증가
- 컨텍스트 스위칭 비용 발생

## 개선방향
- IOCP 서버로 개선(CppIocpServer 프로젝트)
